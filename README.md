Проект 1: Анализ эффективности баннеров в мобильном и десктопном приложении онлайн магазина спортивных товаров.
  
Проект выполнен в качестве кейса компании, занимающейся розничной продажей спортивных товаров. На главной странице компания размещает 5 различнх баннеров с реклмой своейй продукции и своей компанией. 
Цель - оценить эффективность рекламных баннеров в разных версиях и ответить на вопрос обоснованности сдачи рекламного места партнерам. 

Роль - аналитик данных, основные задачи - обработка данных по взаимодействию пользователей с баннерами, анализ конверсий, проведение сравнительного и статистического анализа по платформам, проверка гипотез, формулрование бизнес выводов для выбора маркетинговой стратегии.

Результат
- проведен сравнительный анализ эффективности баннеров в мобильной и десктопной версии приложения + проверена гипотеза, что различия в версиях не случайны
- выявлен уровень вовлеченности пользователей и конверсии по каждому баннеру
- сформулированы рекомендации для маркетологов по целесообразности сдачи рекламных мест компаниям партнерам
- посчитана выгода с точки зрения эффективности и доходности при сдачи рекламного места
  
Как итог, с этого проекта получен опыт анализа межплатформенных рекламных данных и оценки маркетинговых решений, усилены навыки интерпретаций данных в бизнес контексте.
В будущем буду обращать внимание на более глубокую интеграцию с системами компаний и расширение набора метрик.

Чтобы посмотреть код проекта на языке Python - можно скачать скачать файл Sport_goods и загрузить его в google.Colab или Jupyter.Notebook или перейти по ссылке.

Проект 2: Анализ датасета Boston Housing с помощью SQL.

Проект реализован в качестве кейса компании для анализа данных о жилой недвижимости Бостона, который штроко используется для машинного обучения. Цель - использовать язык SQL для работы с реляционными базами данных для изучения данных, выявления закономерностей и зависимостей между характеристиками жилья и ценой.

Роль - аналитик данных, основные задачи - загрузка и подготовка данных в базе, подключение библиотеки sqlite3 в python, написание SQL-запроcов для описательной статистики, группировок, агрегаций, анализа корреляций и проверке гипотез о влиянии различных факторов на цену жилья.

Результат
- выгрузка и структурирование данных о жилом фонде по районам Бостона
- выполнение комплексного набора SQL-запросов, выявляющих статистические распределения, средние значения и корреляционные зависимости
- формирование выводов о ключевых факторах, влияющих на стоимость жилья

Как итог, получен опыт работы с реальными данными при помощи SQL, навыки написания сложных запросов и анализа данных.
В дальнейшем планируется расширить анализ с использованием интеграции SQL с Python и визуализацией результатов.
